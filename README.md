# CodeAlpha Cybersecurity Internship — Task 2: Phishing Awareness Training

## 📌 Project Overview
An interactive web-based training module designed to educate users on identifying phishing attacks, recognizing social engineering tactics, and implementing defensive security habits.

## 🚀 Key Features
- **Core Education:** Clear explanations of common indicators such as domain spoofing, urgency traps, and generic greetings.
- **Interactive Email Simulator:** A real-world email mockup where users analyze headers and links.
- **Automated Quiz Verification:** Instant feedback when users mark emails as legitimate vs. malicious.
- **Remediation Best Practices:** Clear guidance on verifying senders, reporting suspicious activity, and using Multi-Factor Authentication (MFA).

## 🛠️ Technology Stack
- **HTML5:** Semantic structural layout.
- **CSS3:** Custom responsive styling and mock layout design.
- **JavaScript (ES6):** Client-side interactive quiz handling and state logic.

## 💻 How to Run
No external servers or dependencies required. 
Simply open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
